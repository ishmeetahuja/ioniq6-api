Flash the tag

Install the Walk-away Lock firmware on your ESP32 straight from this page. No software to install. Takes about a minute.

1 · Plug in the board

Use a data USB cable (some cables only charge) and a computer with Chrome or Edge.

ESP32classic WROOM-32 DevKit: blue LED
ESP32-C3e.g. C3 SuperMini: blue LED
ESP32-S3e.g. S3-DevKitC-1: RGB LED in blue

2 · Install

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. USB access needs a secure page (https).

Pick the board's port when asked. The right file for your board is chosen for you.

3 · Check it

  1. Unplug the board and plug it back in. The browser can hold it in flashing mode until it's power-cycled.
  2. The LED blinks every 2 seconds: it's waiting for your phone. Once the app connects it stays on.
  3. In the app: Settings → ESP32 tag → Find.

Not working?

  1. No port shows up: try another cable or USB port. Windows may need the CP210x or CH340 driver (the chip name is printed near the board's USB port).
  2. It won't connect: hold the board's BOOT button while clicking Connect, and let go once it starts.
  3. Prefer doing it by hand? Download the .bin for your board from the latest release and flash it at address 0x0.
